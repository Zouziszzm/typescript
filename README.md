# TypeScript

A collection of TypeScript and Next.js projects.

## Projects

### [nihon-main](./nihon-main/)

Interactive Japanese study app — kana and kanji grids, tokenized sentences with hover translations, and cloud TTS with natural pronunciation.

### [Conrad-reader](./Conrad-reader/)

Brutalist PWA novel reader. EPUB, PDF, MOBI, and TXT with offline library, progress tracking, collections, and a built-in dictionary.

### [key-warriors](./key-warriors/)

Turn-based multiplayer typing for 2–3 players. Alternating words, shared WPM/accuracy scoring, live spectator keystrokes, and Hardcore mode.
